Never exceed a provider's low end; spread across providers; keep a reserve for failover.
2. **Failover (10%).** On 402/429/5xx (or a network error) from a provider, pick the next best legal model on a DIFFERENT provider that still has budget, and retry. One provider serves one call at a time — no concurrent calls to the same provider. Count every call. A request whose first call refused must still be served to earn failover credit.
3. **Wires (10%) + served (15%).** Implement all three upstream wires: openai (`POST <base>/v1/chat/completions`), anthropic (`POST <base>/v1/messages`, send the `anthropic-version` header the client sent), gemini (`POST <base>/v1beta/models/<model>:generateContent` or `:streamGenerateContent`). Translate the client's request faithfully in both directions — the provider echoes what it parsed and the client compares that echo with what it sent, so a rewritten or dropped field loses the check (echo_user, echo_tools, echo_max_tokens, echo_image, echo_stop, echo_system, echo_json). Map stop reasons end_turn→stop, max_tokens→length, tool_use→tool_calls, refusal→content_filter. Return the provider's text whole, its usage as that wire reports it, tool calls and their results. On the client's wire, produce the exact streaming event order it expects.
4. **Keep catalog = 100.** The `--list` document must stay byte-identical to the register body.
